# 公开版 v0.3.7

版本号：`0.3.7` / `30700`。

## 本版更新

- 守护日历支持按事件 ID 编辑和确认删除，旧事件会在读取时自动补充稳定 ID。
- 新增“TA 的日记”本机日记本、纸质内容页、搜索、左侧日期抽屉和导入导出备份。
- 日记正文默认显示四行摘要，点击纸页展开全文，再次点击收起；同一时间只展开一篇。
- 放大日记本封面并增加书脊、页边与书签，移除封面文字框并让书名直接居中显示；日记本靠近屏幕视觉中心，守护日历主体适当下移。
- 日记正文使用浅粉米白纸、淡灰紫横线、粉色页边线与柔和心情印章。
- 日记“更多”菜单增加手动添加入口。
- MCP 增加完整的守护日历与日记管理工具。

## 签名与升级

继续使用 `android/signing/zhangxinchuang-public-release.p12` 固定公开版签名，可覆盖安装旧版本。不得删除、替换或重新生成该签名。
